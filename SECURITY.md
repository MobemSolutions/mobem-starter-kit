# Security Policy

## Versions supportées

Ce dépôt est un **template de démarrage** — il n'a pas de cycle de releases stable.
Seule la branche `main` reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

**Ne pas ouvrir une issue publique pour un problème de sécurité.**

Envoyer un email à : **admin@mobem-solutions.com**

Inclure :
- Description du problème
- Étapes de reproduction
- Impact estimé
- Fichier(s) concerné(s)

Réponse sous 72h. Si le problème est confirmé, un correctif sera publié dans les 7 jours.

## Périmètre

| Composant | Couvert |
|-----------|---------|
| Code source du template (`src/`) | Oui |
| Configuration CI/CD (`.github/`) | Oui |
| Dépendances npm (via Dependabot) | Oui |
| Sites clients déployés depuis ce template | Non — responsabilité du développeur |
